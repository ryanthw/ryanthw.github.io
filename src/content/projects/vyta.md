problem: >-
  A fitness tracker is only useful if it closes the loop: logging a workout has to lead
  somewhere. Most student projects stop at the log. The team wanted the app to both
  generate the plan and show whether the plan was working.
approach: >-
  A full-stack Django application built by five people. I integrated the Gemini API to
  generate workout plans from each user's goals and biometric inputs — which meant
  working around input-shaping and API access limits — and built the dashboard's
  visualisations in Chart.js so metrics, goals and progress read at a glance. I also
  handled deployment and hosting on PythonAnywhere, and contributed to the core
  features: authentication, workout logging, goal management and the social component.
result: >-
  A deployed, continuously available application with generated plans, a progress
  dashboard and a working social layer. The repository is public and carries the full
  commit history for the team.
